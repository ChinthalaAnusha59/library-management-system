# Library Management System

A web-based Library Management System developed using Python and Flask to digitally manage library books and user records. The system provides separate access for Admin and Users, making library management easier and reducing manual work.

## Features

### Admin
- Add new books
- Update book details
- Delete books
- View available books
- Manage library records

### User
- Login to the system
- View available books
- Search for books
- View book details

## Technologies Used

- **Python** – Programming language
- **Flask** – Backend web framework
- **SQLite** – Database
- **HTML** – Web page structure
- **CSS** – Styling
- **JavaScript** – Client-side functionality
- **PyWebView** – Desktop application interface
